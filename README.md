# Komentář k zákonu č. 85/2012 Sb., o ukládání oxidu uhličitého do přírodních horninových struktur a o změně některých zákonů

Otevřený komentář k zákonu o ukládání oxidu uhličitého do přírodních horninových struktur — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; povolení provozu úložiště, monitorování, opatření při únicích, uzavření úložiště a přechod povinností, finanční nástroje, veřejná správa, přestupky a příloha k monitorování.

Konsolidované znění: dokument e-Sbírky `SB-2012-00085_2025-07-01`.
